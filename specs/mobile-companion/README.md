# Mobile Companion Specs

## Specs

- `MOBILE_COMPANION_MVP.md`: Android-first Flutter companion, native Pebble
  bridge, local Google API key handling, and phone-side workers for the
  backend-free MVP.
- `ANDROID_PEBBLE_BRIDGE_SPEC.md`: Android native Pebble AppMessage transport,
  Flutter channels, queueing, lifecycle, package visibility, and tests.
- `FLUTTER_UI_SPEC.md`: production setup, API key, permissions, destinations,
  settings, and diagnostics UI.
