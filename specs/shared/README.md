# Shared Specs

## Specs

- `BYOK_PROVIDER_POLICY.md`: credential, provider, privacy, attribution, and
  no-backend policy for Mappy.
- `PROTOCOL_MVP.md`: AppMessage keys, commands, payload formats, lifecycle, and
  error contracts.
- `MAP_TILE_PIPELINE_MVP.md`: phone-generated raster map tile pipeline for the
  Mappy MVP.
- `MAP_ORIENTATION_SETTING_SPEC.md`: north-up versus face-forward centered-map
  orientation preference, follow/manual-browse behavior, and projection
  contract.
- `ROUTING_MVP.md`: phone-side Google route/geocoding flow, route
  simplification, and nav-step generation.
- `SECURE_STORAGE_SPEC.md`: Android native secure API-key storage, redaction,
  clearing, backup, and migration policy.
- `DIAGNOSTICS_SPEC.md`: local structured diagnostic events, redaction, export,
  retention, and cache controls.
- `PROVIDER_ADAPTER_TEST_SPEC.md`: provider fakes, golden fixtures,
  restricted-key checks, and protocol replay coverage.
- `COMPANION_SHARE_MODE_SPEC.md`: Android Google Maps share location/route
  intake, parser, privacy, and watch route-start behavior.
